**QR Code Generator & Scanner - URL Editor**

🚀 **The fastest way to create and scan QR codes with advanced URL editing**

**Key Features:**

✅ **QR Code Generator**
- Instantly convert any URL to QR code
- Generate QR codes from current page with one click
- High-quality QR code output (240x240px)
- Copy QR code image to clipboard
- Download QR code as PNG file

✅ **QR Code Scanner & Decoder**
- Scan QR codes from images (PNG, JPG, WebP, SVG)
- Decode QR codes from screenshots
- Support drag & drop or file upload
- Instant decoding results

✅ **Visual URL Parameter Editor** (Unique Feature!)
- Edit URL parameters visually without typing
- Add, modify, or delete URL parameters easily
- Automatic URL encoding/decoding
- Real-time QR code preview
- Perfect for developers and marketers

✅ **Smart Cache System**
- Auto-save your work to prevent data loss
- Smart detection: use current page or restore previous edit
- Seamless workflow across different pages

✅ **Privacy & Performance**
- All QR generation & image decoding run 100% locally in your browser
- No analytics, no ads, no tracking, no registration required
- All data (history, styles) stored locally via chrome.storage, never uploaded
- The only network access is the optional "decode from image URL" feature, which fetches the image you explicitly provide — nothing else ever leaves your device
- Fast and lightweight

**Perfect For:**
- Developers testing URLs with different parameters
- Marketers creating campaign links
- Anyone who needs quick QR code generation
- Users who frequently share URLs via QR codes

**How to Use:**
1. Click the extension icon
2. Generate: Current page URL automatically loaded, edit if needed
3. Scan: Upload or drag QR code image to decode
4. Copy or download your QR code
